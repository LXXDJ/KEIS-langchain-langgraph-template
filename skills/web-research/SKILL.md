# Web Research

## 개요

주어진 주제에 대해 웹 검색 도구를 활용하여 정보를 수집하고,
수집한 정보를 분석·종합하여 구조화된 리서치 결과를 생성합니다.

## 실행 지침

1. 주제의 핵심 키워드를 추출합니다.
2. `search_web` 도구로 관련 정보를 검색합니다.
3. 검색 결과를 신뢰도 기준으로 분류합니다.
4. 주요 발견사항을 요약하고 출처를 명시합니다.

## 출력 형식

- **요약**: 핵심 발견사항 3~5줄
- **상세 분석**: 주제별 섹션으로 구분
- **출처**: 참고한 URL 목록
