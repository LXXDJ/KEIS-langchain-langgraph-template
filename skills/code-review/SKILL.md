# Code Review

## 개요

코드 diff 또는 파일을 분석하여 잠재적 버그, 코딩 컨벤션 위반,
성능 개선 포인트를 식별하고 구체적인 개선안을 제시합니다.

## 리뷰 기준

- **버그**: 런타임 오류, 논리 오류, 엣지 케이스 누락
- **스타일**: 네이밍 컨벤션, 코드 구조, 중복 코드
- **성능**: 불필요한 연산, N+1 문제, 메모리 누수 가능성
- **보안**: 인젝션, 인증/인가, 민감 정보 노출

## 출력 형식

이슈별로 심각도(🔴 Critical, 🟡 Warning, 🔵 Info)를 표시하고,
각 이슈에 대해 위치, 설명, 개선안을 제공합니다.
